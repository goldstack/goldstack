# Issue and PR Wrangler: disabled

This repository is the open source Goldstack project. Unattended issue and pull
request wrangling is intentionally **disabled** here because it is not
appropriate to expose an agent that triages, comments on and modifies issues
and pull requests on an open source project.

Do nothing. Do not list, comment on, close or modify any issue or pull request,
and do not create branches, commits or pull requests. Exit immediately.
